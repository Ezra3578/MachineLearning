# Workshop 2 - Deep Learning for Fashion-MNIST

Advanced learning models (Part A) applied to the Fashion-MNIST image-classification task
introduced in Workshop 1. The workshop deliverables are a deep learning model, its
training/evaluation code, the best checkpoint and reproducible documentation.

## Phase status

| Phase | Scope | Status |

| 2 | Preprocessing, normalization and `DataLoader` construction | Pending |

| 4 | Training loop, monitoring and checkpointing (`src/train.py`) | Pending |
| 5 | Test-set evaluation vs. Workshop 1 (`src/evaluate.py`) | Pending |
| 6 | Checkpoint loading and inference test (`src/test_model.py`) | Pending |

## Environment setup

Requires Python 3.11 and [uv](https://docs.astral.sh/uv/):

```powershell
uv sync
```

This installs CPU-only PyTorch on Windows (see `[tool.uv.sources]` in `pyproject.toml`).
Register the Jupyter kernel once:

```powershell
.venv\Scripts\python.exe -m ipykernel install --user --name fashion-mnist-dl --display-name "Python 3.11 (fashion-mnist DL)"
```

## Running the notebook

Open `notebooks/workshop2_fashionmnist_dl.ipynb` in VS Code and select the
`Python 3.11 (fashion-mnist DL)` kernel, or execute it headless:

```powershell
jupyter nbconvert --to notebook --execute --inplace `
  --ExecutePreprocessor.kernel_name=fashion-mnist-dl `
  notebooks/workshop2_fashionmnist_dl.ipynb
```

## Dataset

- **Source:** official Zalando mirror, downloaded by Phase 1 and verified against the
  published MD5 checksums before any use.
- **Location:** `data/FashionMNIST/raw/` (gitignored; regenerated by Phase 1).
- **Offline fallback:** if the mirror is unreachable, Phase 1 copies the
  checksum-verified `.gz` files tracked in `Workshop_1/code/data`.
- **Statistics:** Phase 1 writes `data/dataset_stats.json` (provenance, checksums,
  shapes, class balance and pixel statistics).

## Reproducibility

- Seed 42 for Python, NumPy and PyTorch.
- Dependency versions pinned in `pyproject.toml` and `uv.lock`.
- Phase 1 raises on any integrity/checksum failure, so later phases never train on
  corrupted data.
